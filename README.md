# projeto-com-duas-API-nsei

 Proposta
Criar uma aplicação web funcional com arquitetura REST, seguindo o conceito de Mobile First, que consome e exibe simultaneamente dados de duas APIs públicas diferentes (Bored API e Advice Slip API). O projeto roda em um servidor backend construído com Node.js e o framework Express.js, utilizando JavaScript puro (fetch) e manipulação do DOM para atualizar a interface do usuário de forma dinâmica e estilizada.

## Como isso funciona ?
projeto consiste em uma página web responsiva com design Mobile First que roda em um servidor local construído com Node.js e Express.js. A aplicação consome e exibe simultaneamente dados de duas APIs públicas diferentes — uma que sugere atividades práticas para combater o tédio e outra que fornece conselhos de vida aleatórios, utilizando fetch no backend e manipulação dinâmica do DOM no frontend para atualizar a interface com as informações obtidas.
